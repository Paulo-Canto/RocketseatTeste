# SPA blueprint

Neutral single-page app scaffold: layered architecture (`core`, `ui`, `pattern`, `layouts`, `features`, `routes`, `mocks`), TanStack Router (file-based) + Query + Form + Table + Virtual, Zustand, Valibot, MSW, Vitest.

## Requirements

- Node.js 18.18+ (see `engines` in `package.json`). For Vite 7 / Tailwind v4 as in the original spec, use Node 20.19+.

## Setup

```bash
pnpm install
cp .env.example .env
pnpm dev
```

- **MSW**: set `VITE_USE_MSW=true` in `.env` to mock `/api/*` during development.
- **API base**: `VITE_API_BASE_URL` (default `/api`); Vite dev server does not proxy by default—MSW intercepts in mock mode.

## Scripts

| Script | Description |
|--------|-------------|
| `pnpm dev` | Vite dev server |
| `pnpm build` | Typecheck + production build |
| `pnpm preview` | Preview production build |
| `pnpm lint` | ESLint (+ boundaries, oxlint rule turns) |
| `pnpm lint:ox` | Oxlint CLI |
| `pnpm test` | All test suites |
| `pnpm test:unit` | Unit tests (`core`, `features`) |
| `pnpm test:browser` | UI component tests (RTL + jsdom) |
| `pnpm test:integration` | Integration smoke (`routeTree`, etc.) |
| `pnpm analyze` | Bundle visualizer (`stats.html` when `ANALYZE=1`) |

## Route generation

`src/routeTree.gen.ts` is generated by `@tanstack/router-plugin`. It is updated when you run `pnpm dev` or `pnpm build`. Route files under `src/routes/**/__specs__` are excluded via `routeFileIgnorePattern`.
